# Hybrid One-Click 40Q v0.4.0

Primary teacher workflow:

Answered Google Forms score/result link -> one click -> parse questions/answers/images/YouTube -> group unique YouTube videos -> captions first -> Gemini video timestamp alignment -> Whisper/audio fallback when needed -> FFmpeg clip -> fresh 40Q generation -> QA -> optional review.

The normal workflow must not require the Listening Studio tab. That tab remains for advanced/debug use only.
